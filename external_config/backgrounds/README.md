# Header pictures

One folder per place: `landing/` (landing page) and one per section key (`bengali/`, `sports/`, ...).
Every image in a folder (.svg .jpg .jpeg .png .webp .avif .gif, up to 2 MB each) is part of that place's set; the page
picks one at random each visit. Add a file to add an image, delete a file to remove it, then Refresh (or push) to rebuild.
Use wide light-coloured pictures (about 5:1, e.g. 2400x480) with the subject on the right and calm space on the left for the headline.
